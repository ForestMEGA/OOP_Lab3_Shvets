#  Практична робота 3

Цей проект є розвитком другої лабораторної роботи про дрони. Головна мета цієї роботи — реалізувати та показати на практиці механізм перевантаження конструкторів та методів

## Структура проекту
* Drone.cs — клас, який описує характеристики дрона та його поведінку.
* DroneManager.cs — клас, який зберігає список усіх дронів та керує ними.
* Program.cs — текстове меню для взаємодії користувача з програмою.

## Що конкретно було зроблено в Lab-3:

1. **Додано 3 перевантажені конструктори:**
   * Перший — пустий (без параметрів), який дозволяє створювати об'єкт через ініціалізатори.
   * Другий — повний, який приймає всі дані про дрон (ID, модель, батарею, швидкість).
   * Третій — конструктор, який викликає інший конструктор через `this`. Якщо швидкість не вказана, він автоматично ставить її за замовчуванням (60 км/год).

2. **Реалізовано випадкове створення об'єктів:**
   * При додаванні нового дрона програма сама випадково обирає один із трьох конструкторів. Користувач бачить у консолі повідомлення про те, який саме конструктор спрацював.

3. **Додано 3 перевантажені методи польоту:**
   * Перший (базовий) — приймає тільки дистанцію і запускає політ на максимальній швидкості.
   * Другий — приймає дистанцію та нову кастомну швидкість, на якій полетить дрон.
   * Третій — приймає дистанцію та назву спеціальної місії для логування в системі.

4. **Оновлено меню демонстрації поведінки:**
   * У пункті "Продемонструвати поведінку" додано підменю. Користувач може сам обрати, яку саме версію перевантаженого методу польоту він хоче протестувати.

## Як запустити
Відкрийте всі три файли в Visual Studio або VS Code в одному проекті та натисніть клавішу F5.
